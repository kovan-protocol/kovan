# AI usage

AI tools were allowed at HackMeridian 2026, with attribution.

**Rules we followed**
- Every commit containing AI-written code starts with `[ai]`. The few untagged commits are human-written.
- Wallets and owner keys are never created by AI. Owners use their own Freighter wallets; agent signing keys are generated by software (the console or `stellar keys generate`) and never pasted into AI chats or committed.
- Humans made the product and design decisions. Each area below names who reviewed it. Team: Robert Lopez (DevOps Engineer), Esteban Brenes (Product Manager), Sebastián Ceciliano (AI Developer / Designer).
