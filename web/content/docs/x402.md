# Paying with x402

[x402](https://x402.org) lets an API charge per request: the server answers `402 Payment Required` with its terms, the client pays, and a facilitator settles the payment on-chain. On Stellar, the payment is a single USDC `transfer(from, to, amount)`.

## Why a Kovan agent can pay

The covenant judges the **transfer**, not the rail. An x402 payment from an agent's wallet is a USDC transfer like any other: it passes only if the payee is on the agent's providers list and the amount fits its caps, before expiry. A prompt-injected agent pointed at an unknown "paid API" can't pay it.

## Paying from a smart account

The standard `@x402/stellar` client signs only for classic `G…` accounts. Kovan's agents pay from a smart account (`C…`), so the payment is built differently:

1. Request the resource and read the `402` terms: price, USDC asset, `payTo` (a `G…` account with a USDC trustline).
2. Build `USDC.transfer(agentWallet, payTo, amount)` and simulate it to get the wallet's authorization entry.
3. Sign that entry with the agent's key as an OpenZeppelin `AuthPayload` (the signature covers the `AuthDigestPreimage` digest and the rule ID), with an expiration ledger within the facilitator's limit.
4. Send `{ transaction }` as the x402 payment payload. The facilitator verifies and settles it; on testnet, [x402.org](https://x402.org) sponsors the fees.
5. During settlement, Stellar asks the wallet to authorize the transfer, and the wallet asks the covenant. Allowed: the API returns the resource. Refused: nothing moves.

On testnet, an agent paid Stellar's x402 demo endpoint 0.01 USDC this way ([transaction](https://stellar.expert/explorer/testnet/tx/781a5f2b560df66d3d6c587ef4f2a283e82421ce16b54565a9a64a8ba662775d)). A payment to an address outside the covenant was refused by the wallet with `#3904 PayeeNotAllowed`, before anything was submitted.

## Status

x402 payments are implemented in the Kovan console (`dashboard/lib/agent-x402.ts`). They are not yet in `@kovan/sdk` or `kovan.mjs`. Until then, agents pay listed providers directly with `kovan.mjs agent pay` or `prepareAgent("pay", …)`. The covenant applies the same rules either way.
